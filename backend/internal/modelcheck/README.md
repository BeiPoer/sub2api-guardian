# ModelTrace 指纹检测

算法、挑战提示词和 `bank.json` 来源于 [xqy2006/ModelTrace](https://github.com/xqy2006/ModelTrace)，固定版本 `6cd4a8ff0f3f4e49d6d6969dd2fbadfa1569fde2`。原始 MIT 许可保留在 `MODELTRACE-LICENSE`。Go 实现不需要 Python、NumPy 或独立检测服务。

`testdata/reference.json` 由该版本的 `static/fingerprint-core.js` 和 `data/unified_bank.json` 生成，包含三组输入数字序列及完整候选概率，用于校验 Go 移植结果（容差 `1e-10`）。更新指纹库时需同时更新对照数据并运行测试。

每个检测项发送三条独立挑战，每条请求生成 292–332 个 1–355 整数；至少提取请求数量的 55% 才算有效。三条均有效才归因。先进行去环境方向的 Hellinger 中心相似度与有序块特征融合，再用三次查询的校准温度计算 softmax 概率。

三个协议均使用 `stream: true`，后端逐段读取 SSE，只拼接回答文本，排除思考内容与结束事件中的重复快照，收到正常结束信号后才分析指纹。流式错误或异常断流按接口失败重试，丢弃失败尝试的部分输出；拒答、Token 截断仍不参与归因。兼容忽略流式参数而返回完整 JSON 的渠道。OpenAI Chat Completions / Responses 不传 `max_completion_tokens`、`max_output_tokens` 或 `max_tokens`；Anthropic Messages 保留必填的 `max_tokens: 4096`。不额外指定思考深度。页面展示检测进度与最终结论，不展示逐 Token 原文。

读取渠道连接信息或挑战接口报错时，针对失败请求最多重试 3 次，分别等待 3 秒、10 秒、30 秒（首次加重试共最多 4 次）。挑战重试使用同一提示词，已成功的挑战保留；拒答、截断或数字不足不作为接口错误重试。首次请求、重试和间隔等待共享一条“检测中”记录，消息显示当前步骤和重试进度；全部重试失败后才写入最终失败。每次重新发请求前检查取消与定期任务免检／停用条件，服务停止可立即取消等待。单次挑战请求仍限时 3 分钟，整轮上限为 45 分钟，以容纳三条挑战及其重试。

Guardian 根据预期模型的候选库内概率判断：达到 80% 时显示指纹一致；不高于 20% 时显示疑似异常，即使概率分散在多个替代候选上；介于两者之间显示证据不足。预期模型未指定或未出现在本次候选结果中时仅归因。20% / 80% 是展示阈值，不是统计保证；疑似不符不代表已确定具体替代模型，也不证明模型智力下降。候选库为闭集，未收录模型可能被归入任何现有候选。时间线与详情读取时对已有三份有效回答及候选概率的完整记录应用当前判定，无需重新请求上游，不改写原始存储结果。详情单独展示预期模型概率，极小非零概率显示为 <0.1%。

页面默认打开检测总览，按渠道分卡、每个模型一行展示最近 24 次检测（旧在左、新在右，按次数排列）。每个渠道模型独立读取历史，避免高频模型挤掉其他模型。点击色块查看并展开对应记录，弹窗只展示该渠道模型，支持加载更早历史。总览只展示已保存计划中的模型，包括尚未检测的配置项；移除并保存后不再展示该模型，其历史数据保留，重新加入计划后可再次查看。计划与模型选择位于独立的“检测配置”页签。

检测通过管理员导出接口临时读取 API Key 渠道的连接信息，直接调用配置中的模型名，支持 Chat Completions、Anthropic Messages，以及 Chat Completions 端点不存在时回退 Responses。**不会应用 sub2api 的模型映射、代理配置或调度策略**；模型别名需填写该渠道实际接受的请求名。OAuth 等账号的连接测试接口无法可靠传入挑战，因此当前不支持。凭据、原始上游错误正文和原始回答不写入结果。

计划独立于 Guardian 自动守护开关。默认不开启；默认间隔 60 分钟、免检时段 23:00–08:00、时区 Asia/Shanghai。后台每 30 秒检查到期项，定期任务串行执行，间隔从本轮开始时间计算，离线或免检期间不补发历史轮次；免检开始或计划停用后不再发起下一条挑战，已发出的请求可能在此后结束。手动检测忽略定期开关和免检时段，不同渠道／模型可并发执行，同一渠道模型的手动与定期检测互斥。页面仅禁用正在提交或执行的检测项，点击立即检测后停留在列表，可继续启动其他检测项。服务停止时取消并等待全部进行中的检测。运行记录持久化，重启后未完成记录标为中断，移除检测项保留历史。
